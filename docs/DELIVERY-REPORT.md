## 2. سيناريو مونتاج الـHero — الثواني الفعلية

المدة النهائية **12.43 ثانية** · 30fps · بلا مسار صوت · حلقة متصلة.

| # | المصدر | من–إلى | المدة | المحتوى |
|---|---|---|---|---|
| 1 | `12.mp4` | 1.0 – 4.5 | 3.5 ث | جوية واسعة: المنشأة كاملة والحقل الشمسي |
| 2 | `11.mp4` | 0.8 – 3.3 | 2.5 ث | الألواح الشمسية والحظائر خلفها |
| 3 | `13.mp4` | 3.0 – 6.0 | 3.0 ث | الحظائر والطريق الداخلي والشاحنة عند الرصيف |
| 4 | `6.mp4` | 6.6 – 9.6 | 3.0 ث | البيض على السير — **بلا أشخاص وبلا الرافعة** |
| 5 | `12.mp4` | 1.0 – 3.0 | 2.0 ث | عودة للقطة الافتتاحية ليتطابق طرفا الحلقة |

- الانتقالات: **cross-dissolve 0.4 ث فقط**، لا zoom ولا speed ramps ولا حركة كاميرا مصطنعة.
- **7.mp4 و8.mp4 لم تُستخدما** في الـHero إطلاقاً.
- **اختيار نافذة 6.mp4 مبني على فحص:** الرافعة تسيطر على المشهد حتى ~6 ث، وأول عامل يظهر عند **11.5 ث**. النافذة النظيفة الوحيدة هي 6.0–11.0 ث.

### الحلقة
آخر 0.5 ث تُمزج مع بداية الفيديو نفسه، فيصبح الإطار الأخير هو الإطار الأول.
**مقاس فعلياً:** فرق أول/آخر إطار = **1.14/255** للديسكتوب و**2.69/255** للجوال — أي غير مرئي.

## 3. المعالجة البصرية — مبنية على قياس لا تخمين

قِيست اللقطات الأربع أولاً:

| اللقطة | R | G | B | R−B | stddev | محترق |
|---|---|---|---|---|---|---|
| 11 شمسية | 133.0 | 121.1 | 111.3 | **+21.7** | 47.5 | 0.83% |
| 12 جوية | 145.5 | 129.4 | 113.8 | **+31.8** | 33.3 | 0.18% |
| 13 حظائر | 131.1 | 123.5 | 117.3 | **+13.9** | 40.2 | 0.31% |
| 6 داخلي | 182.4 | 183.9 | 205.4 | **−23.1** | 31.4 | 1.32% |

الجوية الثلاث تحمل ميلاً دافئاً يزداد بالارتفاع، والداخلي أزرق بقوة من إضاءة الصالة.

**السلسلة:** `deblock` → `hqdn3d` → `colorbalance` (لكل لقطة قيمها) → `curves`
(استعادة السنام الأبيض + رفع ظلال معتدل) → `eq` → `unsharp` خفيف.

**النتيجة بعد التدريج:**

| اللقطة | R−B | الطيف | محترق |
|---|---|---|---|
| 12 جوية | **+14.6** | — | 0.33% |
| 11 شمسية | **+15.1** | — | 0.23% |
| 13 حظائر | **+14.1** | — | 0.14% |
| 6 داخلي | −3.9 | **5.6 درجات** | 0.22% |

الجوية الثلاث صارت متطابقة (14.1–15.1) فتبدو كنهار واحد، والصالة صارت بيضاء
محايدة بدل الأزرق، وسقوف الحظائر استعادت تفاصيلها (1.32% → 0.22%).

**لم يُستخدم:** Fake HDR · حدة مبالغة · تشبع برتقالي · سماء مصطنعة · غيوم ·
lens flares · ضباب · تغيير المنشأة · معدات مضافة · تفاصيل مخترعة في الـupscale.

> **تصحيح أثناء العمل:** المرور الأول ترك ميلاً ماجنتا في الصالة (G أقل من R وB).
> اختُبرت ثلاث معايرات على إطار ثابت واعتُمدت التي أعطت أضيق طيف (5.6 درجة).

## 4. الشعارات القديمة — لا وجود لها

**اللقطات الأربع الجديدة نظيفة أصلاً.** فُحصت زوايا 12 و11 و13 و6 بدقة كاملة:
لا شعار ولا `dji`. لذلك **لم يُستخدم أي قص** — الإطار كامل 1280×720 وبلا تشويه،
وهذا ما ألغى الحاجة لقص 848×330 الذي كان ينتج نسبة 2.57:1 غير صالحة للجوال.

**الفحص النهائي (المطلوب في البند 21.16):** مُسحت **جميع** إطارات الملفات الثلاثة
عند 4fps — 50 إطاراً للديسكتوب و50 للجوال و21 للأتمتة — وقُصّت زاويتا كل إطار
(أعلى-يسار وأسفل-يمين) في لوحات تحقّق: **242 قصاصة، صفر شعار**.

## 5. نسختان حقيقيتان

| | Desktop | Mobile |
|---|---|---|
| الملف | `hero-desktop.mp4` | `hero-mobile.mp4` |
| الأبعاد | **1920×1080** | **1080×1920** |
| النسبة | 16:9 | 9:16 |
| الإطارات | 30fps | 30fps |
| المدة | 12.43 ث | 12.43 ث |
| الترميز | H.264 High | H.264 High |
| الحجم | **10.12 MB** (الحد 15) | **6.26 MB** (الحد 9) |

**نسخة الجوال إعادة تأطير مستقلة لقطة بلقطة، لا center-crop:**

| اللقطة | مركز القص أفقياً | رأسياً | التكبير |
|---|---|---|---|
| 12 جوية | 0.44 | 0.56 | 1.30 |
| 11 شمسية | 0.42 | 0.62 | 1.16 |
| 13 حظائر | 0.40 | 0.55 | 1.28 |
| 6 السير | 0.30 | 0.82 | 1.28 |

التكبير أُبقي عند أدنى حد تسمح به كل لقطة — كل 0.1 إضافية حدة حقيقية مفقودة من
مصدر 720p. رُوجعت التأطيرات على لوحة 9:16 مع تحديد منطقة النص قبل الترميز،
وأُعيد ضبط لقطتَي السير والشمسية لأن موضوعهما كان يقع خلف العنوان.

**WebM لم يُنتَج:** قِيس VP9 على هذه اللقطات فجاء **أكبر** من x264
(10.53 مقابل 10.12 ديسكتوب، 6.94 مقابل 6.27 جوال) — فملف ثانٍ يكلّف بايتات بلا فائدة.

### Posters منفصلة
`hero-poster-desktop-{1280,1600,1920}` بنسبة 16:9 · `hero-poster-mobile-{720,900,1080}`
بنسبة 9:16 حقيقية — كلاهما AVIF + WebP + JPG، ومُحمَّل مسبقاً خلف media query خاص به.

## 6. الأدلة التقنية المطلوبة

### currentSrc والأبعاد و muted

| | 1440px | 390px |
|---|---|---|
| `currentSrc` | **hero-desktop.mp4** | **hero-mobile.mp4** |
| `videoWidth×Height` | **1920×1080** | **1080×1920** |
| `muted` | **true** | **true** |
| `defaultMuted` | **true** | **true** |
| `loop` / `playsInline` | true / true | true / true |
| `preload` | metadata | metadata |
| `duration` | 12.43 | 12.43 |
| poster المستخدم | `hero-poster-desktop-1600.avif` | `hero-poster-mobile-720.avif` |
| شعار الهيدر | 128px | 105px |
| شعار الفوتر | 190px | 155px |

`muted` كان يقرأ false سابقاً؛ الآن يُضبط كخاصية على العنصر عبر `effect` بعد إنشائه،
لا كسمة HTML وحدها. ولا يحتوي أي ملف على مسار صوت أصلاً (`-an` في الترميز).

فيديو الأتمتة: `automation.mp4` · 1920×1080 · 5.23 ث · muted · loop · playsInline ·
`preload="none"` ولا يُحمَّل إلا عند الاقتراب.

### نتائج الضغط الفعلي على روابط القائمة

ضُغطت الروابط الأربعة فعلياً (لا فحص href):

| الرابط | الديسكتوب | الجوال |
|---|---|---|
| الإنتاج → `#automation` | ✅ scrollY 1731 · sectionTop **72px** | ✅ scrollY 1342 · القائمة أُغلقت · التمرير استُعيد |
| المنتجات → `#products` | ✅ scrollY 3222 · sectionTop **72px** | ✅ scrollY 2326 |
| المزرعة → `#facility` | ✅ scrollY 5062 · sectionTop **72px** | ✅ scrollY 3833 |
| تواصل معنا → `#contact` | ✅ scrollY 6918 · sectionTop **72px** | ✅ scrollY 5088 |

`sectionTop = 72px` هو `scroll-margin-top` بالضبط — **الهيدر لا يغطي بداية أي قسم**.

> **سببان حقيقيان اكتُشفا وأُصلحا:**
> ① الراوتر كان يملك العنوان فلم يعمل `href="#id"` إطلاقاً.
> ② بعد إضافة الخدمة، `scrollPositionRestoration: 'top'` كان يعيد الصفحة للأعلى
> فور استدعاء `router.navigate`. الحل: `history.replaceState` بدل الراوتر،
> و`anchorScrolling: 'disabled'` لأن الخدمة تتولى ذلك.

```

/en/index.html   <html lang="en" dir="ltr">   53 KB

  canonical   https://familyeggs.sa/en
  hreflang    ar → /ar · en → /en · x-default → /ar
```

**زاحف لا يُنفّذ JavaScript يحصل على المحتوى كاملاً باللغة الصحيحة لكل مسار.**

### الشعار في الهيدر — قرار يستحق الذكر
الشريط كان شفافاً فوق الـHero، وهذا أجبر على استخدام الأيقونة بلا اسم لأن
الكتابة التراكوتية تعطي **2.2:1** فقط على الفيديو الداكن. وأنت طلبت أن يُقرأ اسم
العلامة. الحل: **شريط عاجي ثابت من أول الصفحة** — الشعار الكامل بالاسم مقروء من
الإطار الأول، والفيديو يظل يملأ الشاشة خلفه. لم يُعَد رسم الشعار ولم تتغير ألوانه.

## 9. التشغيل

```bash
npm start                          # تطوير
npm run build                      # بناء + prerender لـ/ar و/en
npm run serve:prod                 # بدون -s (المخرجات ثابتة لكل مسار)

python tools/build-hero.py         # الـHero والأتمتة كاملة
python tools/build-hero.py stills   # لوحة تدريج قبل/بعد
python tools/build-hero.py framing  # لوحة تأطير 9:16 مع منطقة النص
python tools/build-media.py        # الصور والشعارات والأيقونات
python tools/build-fonts.py        # Madani Arabic → WOFF2
```
